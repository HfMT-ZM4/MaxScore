This folder contains two versions of DJster:
- a 2008 port of Barlow's AUTOBUSK as a kind of standalone application. It imports files created for the original Atari program.
- a 2016+ version embedded in the Max environment as a bpatcher. It is much more flexible than the earlier version and also runs in Ableton Live.

In addition, this folder contains educational materials in the Indispensibility and Tonality subfolders. Open the enclosed help files for further information.
